# Сайт-приглашение с отправкой ответов в Telegram

## Что делает интеграция
- Гость заполняет форму и нажимает «Отправить ответ».
- Браузер отправляет сведения на `/api/rsvp`.
- Сервер пересылает ответ Telegram-ботом в указанный личный чат.
- Токен бота хранится только в переменных окружения сервера, не в HTML.
- Если отправка не удалась, сайт показывает сообщение и оставляет текст ответа для ручного копирования.

## 1. Создай Telegram-бота
1. В Telegram найди официальный `@BotFather`.
2. Отправь `/newbot`, следуй подсказкам и сохрани выданный токен. Не публикуй токен и не отправляй его в чат с помощником: тот, кто знает токен, может управлять ботом.
3. Открой ссылку на созданного бота и отправь ему `/start` со своего личного аккаунта.
4. Узнай свой числовой Telegram ID у бота вроде `@userinfobot`. Для личных сообщений используй его числовой ID как `TELEGRAM_CHAT_ID`.

Если нужно отправлять ответы в группу вместо личного чата, добавь туда бота, напиши сообщение в группе и используй ID группы; он обычно отрицательный. Для первой настройки личный чат проще.

## 2. Задай секреты
Скопируй `.env.example` в `.env`, затем укажи настоящие значения:

```env
TELEGRAM_BOT_TOKEN=токен_из_BotFather
TELEGRAM_CHAT_ID=твой_числовой_ID
```

Файл `.env` исключён из Git через `.gitignore` — не загружай его в публичный репозиторий и не отправляй другим людям.

## 3. Проверь локально
Нужен Node.js версии 18 или новее.

```bash
npm start
```

Открой `http://localhost:3000` и отправь тестовый ответ. Проверить, что сервер запущен и переменные настроены, можно по адресу `http://localhost:3000/api/health` (поле `telegramConfigured` должно быть `true`).

## 4. Разверни сайт с API
Для отправки на Telegram нужен сервер; обычный статический хостинг не выполнит `/api/rsvp`.

Вариант с Render:
1. Собери полный проект сайта в одну папку: этот `index.html`, `server.js`, `package.json`, `render.yaml`, папку `Data` и все исходные фотографии/декор/шрифты сайта.
2. Загрузи проект в свой GitHub-репозиторий. Не загружай `.env`.
3. В Render создай **New + → Web Service** и подключи репозиторий. Для параметров используй Node runtime, Build Command `npm install`, Start Command `npm start`.
4. В настройках **Environment** добавь `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, затем сохрани и разверни сервис.
5. Открой выданный Render URL и проверь тестовую отправку. Если сайт уже подключён к собственному домену, привяжи домен к новому Web Service по инструкциям хостинга.

## Важно про исходные ресурсы
В присланном наборе файлов не было самих изображений и шрифтов. Сохрани существующие ресурсы из оригинального проекта в папке `Data` (например, `photo1.jpg`–`photo4.jpg`, `main-decor.webp`, `my-custom-font.ttf`, если такие файлы используются). CSS должен лежать по адресу `Data/styles.css`.
